Here is my phpMyAdmin report for May 2020.

<!-- more -->

In May 2020 I worked on the JavaScript dependencies, which I moved to a package manager, on the selenium test suite and on a lot of code cleanup.

## First week (18)

I moved most of the JavaScript dependencies to a package manager and improved the vendor sync script, copying the jQuery plugins from their npm packages (jquery-fullscreen-plugin, jquery-debounce-throttle, jquery.ba-hashchange, jquery-uitablefilter, tablesorter). I added the `CaptchaSiteVerifyURL` config for reCaptcha, fixed the bookmarked query overwrite fatal error and merged a fix to allow simplifying the exported view syntax. On sql-parser I merged a fix to not allow numbers with letters. I also updated the cdnjs entry for jquery-fullscreen-plugin 1.1.5.
