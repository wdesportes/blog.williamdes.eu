Here is my phpMyAdmin report for June 2020.

<!-- more -->

In June 2020 I fixed bugs, including a security fix on the 404 page, removed the underscore prefixes from method names and worked on the Twig 3 support.

## First week (23)

I merged several fixes on the main repository: the Designer with table names having spaces, the MySQL 8.0.11+ ALTER USER privileges, the ENUM and SET display when editing routines and the process list keeping its state on auto refresh. I also removed the underscore prefix from all method names. On the docker repository I added SHA checksums when downloading a version.

## Second week (24)

My focus of the week was the Twig 3 support, which meant upgrading motranslator and twig-i18n-extension. I released twig-i18n-extension 3.0.0 and reworked the selenium test suite to only use the GUI, dropping the mysqli connection. I also fixed a XSS on the 404 page (unescaped route) and made the export stream the data and clean all buffer levels. On the Debian side I bumped debhelper-compat to 13 for all our packages.
