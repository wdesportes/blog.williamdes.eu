Report for June 2018

Author: William Desportes
Published: June 1, 2018 12:00 and updated: November 10, 2026 12:00 · 4 min read

Here is my phpMyAdmin report for June 2018.

First week (22)

I replaced apigen with Sami in the CI of the main repository (#14345), with a generated configuration in test/. I also fixed #14295 and #14348, where an unknown $cfg['ThemeDefault'] theme ended in a 500 error. This was the first step of a change that took two years to land: Sami was itself unmaintained, and in 2020 I forked it as Doctum and moved every library onto it.

  • ffc40cc517 - Replace apigen with Sami in CI
  • a87bf74eed - Fix for #14295
  • d26f7e47fb - Patch for issue #14348

Second week (23)

I fixed #14370, where a query returning no row, like SELECT * FROM mytable WHERE 0, made mysqli::fetch_array return NULL and raised an error, and prevented JavaScript errors from being reposted (#14359). I also replaced apigen with Sami on sql-parser, motranslator and shapefile, each with its configuration next to the CI, so the whole set of libraries used the same documentation generator.

  • a9dce0b40e - Fixes #14370
  • fa303ee292 - Prevent reposting of javascript errors
  • 981c49945a - PHPDOC fix
  • b1ca941675 - Replace apigen with Sami in CI
  • 20d53bd6d0 - Replace apigen with Sami in CI
  • aaff2200a7 - Replace apigen with Sami in CI

Third week (24)

I added phpstan to the project, with its bootstrap file, configuration and a CI job. The designer gave me most of the work: a database named '"><iframe onload=alert(1)> executed its iframe on the new page, so I escaped the database name in the URLs and used rawurlencode and Twig's url_encode. I also moved its configuration to JSON, fixed a template loop that ran one iteration too many and handled a database without tables. I fixed the missing index icon (#14225), made a security fix for the structure page (#14374), fixed the search and insert dropdown broken by an integer foreign key (#14388) and added support for the commondir file in .git directories (#14391).

Fourth week (25)

On the website I added the migrate command to the README, test data for #73 and fixed the CVE links. On the main repository I completed the escaping of the database name in URLs.

Fifth week (26)

I fixed the 2FA QR code generation with PHP GD (#14171), the missing "Visualize GIS data" icon (#14382) and a missed case of passing an extension to Util::getImage (#14390). I also reached phpstan level 0, which meant cleaning phpdoc, class names, duplicate array keys and undefined properties.

Other projects

Outside phpMyAdmin I fixed a broken link to the Library of Babel on cakenggt/Library-Of-Pybel (#5) and aneopsy/LibraryOfBabel (#1), and updated the screenshots of dwyl/learn-travis while migrating it to travis-ci.com (#44). In June 2018 I worked on the main repository, the website and the small libraries, mostly on CI and static analysis.
