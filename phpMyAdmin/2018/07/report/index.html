Report for July 2018

Author: William Desportes
Published: July 1, 2018 12:00 and updated: November 10, 2026 12:00 · 2 min read

Here is my phpMyAdmin report for July 2018.

In July 2018 I backported my June fixes to the QA_4_8 branch and worked on the documentation of the MySQL and MariaDB variables.

First week (27)

I fixed #14457, where mb_substr returned null, and backported to QA_4_8 the fixes I had made in June for the 2FA QR code (#14171), the missing "Visualize GIS data" icon (#14382) and the missed Util::getImage call (#14390). Outside phpMyAdmin I fixed the constants of ins0/github-changelog-generator (#14).

  • bdd60af282 - Fix #14457 - mb_stubstr null
  • 93ec29933b - Fix - #14382 "Visualize GIS data" icon missing
  • 863badfdc2 - Patch - missed instance of 'Avoid passing extension to Util::getImage'
  • 71ae2b2e68 - Fix for #14171 - 2FA QR PHPGD

Second week (29)

I fixed the type error reported in #14488.

  • a23a3a7776 - Fix #14488 - Type error

Third week (30)

I added support for the MySQL and MariaDB variables documentation: the help now sends MySQL users to the MySQL documentation and MariaDB users to the MariaDB one, through a new williamdes/mariadb-mysql-kbs package. The unit tests now use data that only exists for the tests. On phpmyadmin/scripts I added phpdoc, fixed coding style errors and added support for push events (#14, #15).

  • 38009efb65 - Add support for MySQL/MariaDB variables documentation
