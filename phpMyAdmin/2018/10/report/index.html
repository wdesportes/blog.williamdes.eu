Here is my phpMyAdmin report for October 2018.

In October 2018 I worked on the main repository, mostly on the test infrastructure.

First week (41)

My focus of the week was the test setup: I migrated the tests to facebook/webdriver, added a TESTSUITE_PORT variable for the Selenium tests, tried several browsers and a new Travis setup, and rewrote the Browserstack script from the local testing manual. I removed some phpstan ignores by enabling reportUnmatchedIgnoredErrors, which warns when an ignore is not needed anymore. I also fixed a designer error (#14223).

Second week (43)
