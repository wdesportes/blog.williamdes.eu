Report for December 2018

Author: William Desportes
Published: December 1, 2018 12:00 and updated: November 10, 2026 12:00 · 4 min read

Here is my phpMyAdmin report for December 2018.

In December 2018 I merged a batch of fixes on the main repository and reviewed contributions: the left and right icons, the Git revision error, exporting a view structure and the SQL export for tables. I also backported the commondir support to QA_4_8 and merged sql-parser pull-requests.

First week (48)

I fixed the left and right icons that were hidden (#14764) and cherry-picked the fix to QA_4_8.

  • 61b98cf9cc - Merge branch 'QA_4_8'
  • 6858635d60 - Add ChangeLog entry for #14764
  • b5372b840c - Fix #14764 - left/right icons hidden

Second week (51)

A week of bug fixing. The Git revision check raised an error on the first page load (#14635, #14762); I fixed it and added tests for Config::checkGitRevision and Config::isGitRevision. Exporting a view structure based on another view with a sub-query threw "No database selected" (#13788), the SQL format was not offered for table exports (#14775), a php warning came from urldecode() in db_export.php (#14791) and the Text_Plain_Sql plugin froze the interface (#14794). I also fixed the missing table level Operations functions (#14786), merged #14810 for the browser display transformation selection (#14756) and backported the commondir support to QA_4_8. On sql-parser I merged two pull-requests: PURGE statements (#208) and tests for the CREATE OR REPLACE VIEW builder (#209).
