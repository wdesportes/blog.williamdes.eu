Report for March 2019

Author: William Desportes
Published: March 1, 2019 12:00 and updated: November 10, 2026 12:00 · 10 min read

Here is my phpMyAdmin report for March 2019.

In March 2019 I worked on the main repository and sql-parser, closing a long list of bugs, one ChangeLog entry at a time, and merging every fix back into the 4.8 branch.

First week (9)

I fixed a series of tracker issues: the date and time inside exported ZIP files (#14870), the Null checkbox that unmarked itself (#14425), the blocked bottom table (#14898), the missing query time in German caused by the decimal number format (#13975), the charset used for MS Excel exports, now windows-1252 (#14837), and a JSON encode error (#14922). I also fixed the refresh icon on expanded databases (#14896), removed a stray space in the X-Forwarded-For header, and cleaned up the code style.

Third week (11)

I fixed error reporting and the GIS editor on multi server setups, and prevented multiple error reporting modals from opening (#14359). When a config-set command fails we now show the error instead of "loading..." forever. I also found why PMA_messages was undefined: the session folder had no access permissions, so index.php was loaded as a script and the messages were never defined (#14826). On top of that I fixed an undefined index in the setup script (#14311), removed the inline styles from the server status monitor (#12262, closing #14980) and fixed the TypeError in the GIS editor (#14991).

Fifth week (13)

The week started with a security fix on the designer: the database name is now escaped when saving a page. I also fixed a series of multi server setup problems (sending an error report, removing partitioning, the query format, the new table and listing modal), the RESET SLAVE button on a replication slave, and column normalization, which now takes the server parameter and uses POST. For the download of monitor parameters I added a small delay, some browsers were reporting the blob as a 404. Then I closed a batch of issues: designer errors (#14816, #15110), virtual columns on the insert page (#14853), the virtuality not selected when editing a generated column, with the VIRTUAL/STORED option added for MariaDB (#14957), deleted tables on the last page (#14205), incorrect page numbers (#15077, #15100), the view edit form (#14916, #14926), the comments format (#15095) and the hover box and login layout on the original theme (#15071, #15065).
