Report for April 2019

Author: William Desportes
Published: April 1, 2019 12:00 and updated: November 10, 2026 12:00 · 11 min read

Here is my phpMyAdmin report for April 2019.

In April 2019 I worked on the main repository, the website and docker, fixing issues all month. I also rewrote my github-to-mysql tool, moving all the code to a class and adding unit tests, and made it handle several pages of milestones and labels (wizaplace/github-to-mysql #4).

First week (14)

I fixed a long list of tracker issues: the missing query time and database in the console (#15159), uninterpreted HTML on the Settings export page (#15119) and import page, the input fields missing the MaxSizeForInputField check (#15036), the Export/Import tabs placement (#15152), the import of XML data with leading zeros, the generate password field hidden on the second open of the change password modal (#15150), the empty SQL preview on a relation (#15010), a table structure export that showed the rows fields (#14334), the edit link that stopped working after a failed insert (#15140) and the sticky table header staying over the dropdown menu (#12729). I added the DYNAMIC and COMPRESSED ROW_FORMAT values for InnoDB on MySQL 8 (#14673), made the monitor parameters download work on IE11 and Edge, and fixed several PHP notices (undefined index pma, designer_settings #15141) and a count() warning when exporting a table to XML. On the website I merged two pull-requests improving the English and fixed a missing accent on the docker side.

Second week (16)

I fixed the GIS functions on MySQL 8.0 (#14383, #12865), which I also proposed as pull-request #15149. MySQL 8.0 puts each point of a MULTIPOINT between parentheses, so I corrected the value format, and I fixed the undefined mysqlVersion index that came with the change.

  • ccc82e82b5 - MULTIPOINT now has ( and ) around value
  • c745aab360 - Fix php notice Undefined index: mysqlVersion
  • 3399e5babd - Fix spatial functions
  • 9ed068aacb - Fix #14383 #12865 - Fix GIS functions for mysql 8.0

Third week (17)

I fixed a large batch of issues: uppercase table and database names (#13178), error reports that could not be sent because too large (#15146), the Processlist sort by time and full query display (#14800, #14833), the import of settings (#14527), the designer page that failed to save (#12900), and the MariaDB delete versioning rows privilege that raised an undefined index notice (#15229). I also fixed the Enter key when inserting rows (#14401), the enum value kept when setting null (#14982), useless backquotes in the SQL preview when deleting an index (#15205), the password field not switching in the add user account dialog (#15219), a console height allowing negative values (#15038) and forms submitted multiple times on CTRL+ENTER (#14460). Importing an exported config on the server status monitor page was fixed too, a missing series value was creating a JavaScript error and a NaN on the Y axis. Weblate brought a lot of translations, and I had to revert, merge and re-apply two po files to get around the conflicts.
