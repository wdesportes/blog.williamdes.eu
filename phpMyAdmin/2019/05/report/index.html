Report for May 2019

Author: William Desportes
Published: May 1, 2019 12:00 and updated: November 10, 2026 12:00 · 10 min read

Here is my phpMyAdmin report for May 2019.

In May 2019 I worked on the main repository, sql-parser, docker and the error reporting server. On the side I fixed the time type handling in node-mysql2, '00:00:00' is now returned as a string (#968), and the JWT expiration on octokit/app.js (#33).

First week (18)

I fixed a lot of small issues: the authentication failure page that did not consider SignonCookieParams (#14412, with a new test for setCookieParams), the unexpected behaviour of the Settings reset button (#15037), the multiple errors printed on the Settings page (#15043) and a JSON response shown when returning back to a Settings form with errors (#15240). I also fixed the JavaScript error when editing a JSON data type column (#14301), a TypeError on textContent (#15239), the password copy when copying a user on Percona Server 5.7 (#13726), the privileges of procedures not shown in 4.8.5 (#15238) and the Settings tab not marked as active on the 2FA page (#15157). The error reports themselves were fixed too: the notices when reporting errors are gone (#14992), the current web page url and the real JavaScript file name are reported again, all JS files used to be reported as index.php, and reports too large to be sent are truncated like the PHP side does (#15146). I back-ported the MySQL 8.0 GIS fix (#14383, #12865) and the stored procedure fix (#14614) to the 4.8 branch. On the error reporting server I updated the README, the .gitignore and the configuration setup guide (#182).

Fifth week (22)

I fixed the collation changes: an empty input is now checked (#14987), the operations page uses POST instead of REQUEST, and phpMyAdmin no longer tries to change the collation on views when changing all tables (#15283). I also fixed the auto_increment field that was too small (#15287) and the logo link for internal links, with the documentation updated (#15041). On sql-parser I reverted most of a cleanup I did not want in that branch: the new array syntax, the strict mode on PHP files and the bump to PHP 7.1. I also removed the coding-standard package, downgraded phpcs from 3.4 to 2.9.x and fixed the CLI test.
