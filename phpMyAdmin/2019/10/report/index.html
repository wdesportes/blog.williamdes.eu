Report for October 2019

Author: William Desportes
Published: October 1, 2019 12:00 and updated: November 10, 2026 12:00 · 8 min read

Here is my phpMyAdmin report for October 2019.

In October 2019 I worked on the main repository, the Debian tcpdf packaging, sql-parser and docker. On the website I updated the relationship attribute of the sponsored links (#95).

First week (40)

One commit only this week: a patch for the phpunit tests on the Debian packaging of sql-parser, for upstream commit cc9406f4a0ed122.

  • 6478b431dd - Add patch for phpunit tests upstream:cc9406f4a0ed122

Second week (42)

I fixed the privileges check that answered "You do not have privileges to manipulate with the users!" to a root superadmin (#14433), the referential integrity check that showed the table content (#14598), and the export of users that deleted all the selected users after a delete (#15511). I also fixed a text area overflowing its parent element (#15161), the bottom table of the left pane blocked by the horizontal scroll bar (#14898), the plus sign in a table or database name when configuring foreign keys (#15482) and a deprecated unparenthesized ternary (#15499). On the test side I added a Travis CI config, group annotations and fixed several deprecated phpunit methods. On the Debian packaging of tcpdf I packaged 6.3.2, fixed the watch file, the reprotest and the VCS URLs, and added a default block for gbp.conf.

Third week (43)

I fixed the privileges adjustment when copying a database with MariaDB (#15311), the GIS polygon of a geometry field that was not drawn anymore, introduced by my MySQL 8 fix (#15391), and the referential integrity check for InnoDB (#15477). I also fixed the designer table list to allow strange table and database names, used the database instead of table.db in one place (#15485) and used a translation for "select all". On docker I improved the Travis CI file with steps, merged a pull-request for it and reverted the increase of the upload and post limits.

Fourth week (44)

I fixed the HTTPS/HTTP cookie separation issue, the one that says "Failed to set session cookie. Maybe you are using HTTP instead of HTTPS" (#14184), and the Sort By Key issues (#15475), co-authored with Vitalii Medvediev. I also fixed an uncaught TypeError on htmlspecialchars in the navigation tree (#15540) and removed the ic_b_info icon (#15522). On sql-parser I added the parsing of the TRUNCATE statement (#221) and of the CHECK keyword on table definitions (#264), and fixed the implode argument order (#258).
