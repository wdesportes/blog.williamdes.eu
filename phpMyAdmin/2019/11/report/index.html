Report for November 2019

Author: William Desportes
Published: November 1, 2019 12:00 and updated: November 10, 2026 12:00 · 10 min read

Here is my phpMyAdmin report for November 2019.

In November 2019 I worked on the main repository, sql-parser, docker and the Debian phpMyAdmin packaging. On the side I fixed the build of crocodile2u/mariadb-rocks with the docker image 10.4 (#1) and added a GitHub CI to mariadb-mysql-kbs (#80).

First week (44)

I merged the HTTPS/HTTP cookie separation fix (#14184, pull-request #15273) and updated the error report test after it. On sql-parser I merged the fix for the wrong parsing of partitions (#265, for phpMyAdmin issue #13951), fixed the PHP compatibility of the array syntax and set the last CHANGELOG entry as unreleased.

Second week (45)

I merged two pull-requests fixing the export, which was removing aliases or cross joins (#12241, #15316 and a few other issues closed with them). I also fixed moving columns with DEFAULT NULL on MariaDB 10.2+ and with type INT and default CURRENT_TIMESTAMP (#14951), and unblocked the UI when column_info is detected as working but does not. The Long2IP issue with PHP 7.1 was fixed (#14906), the test suite was made 32bit compatible and more flexible, and I fixed the redirects and broken links in the .rst documentation and the is_uploaded_file() error (#14809).

Fourth week (47)

A big week on the designer: I applied the security patch for the Designer and its visual mode (CVE-2019-18622, PMASA-2019-5), improved the select all checkbox process, fixed the display field process and added a message when the designer is misconfigured; adding a table from the list no longer crashes the designer when it is impossible. I also fixed the broken Twig function (#15589), the user warnings, errors and notices that were shown (#15592), an undefined index foreign_keys_data (#15591), the middle click on table sort columns (#15434), the panels of the homescreen going underneath the floating menubar (#15570) and the profiling chart, now displayed when the output has no rows. The Debian package for 4.9.2 was updated.
