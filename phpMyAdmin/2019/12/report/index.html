Report for December 2019

Author: William Desportes
Published: December 1, 2019 12:00 and updated: November 10, 2026 12:00 · 15 min read

Here is my phpMyAdmin report for December 2019.

In December 2019 I worked on the main repository, sql-parser, docker and the Debian phpMyAdmin packaging.

First week (1)

I fixed several bugs: an error 500 when exporting, which needed a time limit (#15725), the extra line break in downloaded blob content (#15666), the database structure that failed with a PHP error on a replicated server (#15722), tables that could not be browsed since the 5.0.0 update (#15723) and NULL that was no longer displayed on numeric fields (#14936, a partial revert of my own phpstan level 1 work). I also removed a useless url_encode (#15669) and prevented the size column of the database structure from wrapping (#15637). On sql-parser I added the DROP USER statement (#259), the missing options in the SET statement (#255), SCHEMA in CREATE DATABASE (#231), fixed the LIMIT offset overwritten by parentheses (#275) and a notice on ORDER BY (#249), and added tests for CALL, TRUNCATE and the CLI stdin, plus PHP 7.4 in the test matrix.

Fourth week (51)

I worked on the CI: I added a PHP 7.4 step using phpunit 8, disabled xdebug for the 7.4 and selenium runs, fixed the OSX build and its mysql password, and ignored yubico.com and the secure.php.net redirection in the link checks. On the main repository I fixed a series of issues: Show Processlist throwing an exception (#15677), DisableIS broken with a controluser on 4.9.2 (#15608), the replication actions not sent to a mysql link (#15641), renaming a primary key with auto increment (#14732), the datetime picker and modal UI (#15623), the ReCAPTCHA callback (#15435) and a JavaScript error on the query statistics page when the user has not enough privileges. Outside of the tracker I fixed the deprecated Twig spaceless tag and for-if, replaced the filter tag by the apply tag, and fixed several PHP 8.0 notices.

Fifth week (52)

I fixed several issues reported after the 5.0 release: the disabled time input of the datetime picker (#15695), the import status URLs, the Timestamp method that did not take the current time (#15682), the calendar z-index on the original theme (#14248), a TypeError in the export page (#15697) and a JavaScript error on the query statistics page when the user has not enough privileges (#15692). I also added some typecasts and phpdoc blocks for phpstan and reduced the duplication around the NodeFactory calls. On docker I implemented the *_FILE environment variables (#247), the override of the configuration with a base64 encoded config (#192, #262) and the UPLOAD_LIMIT setting (#261), and documented which tags we offer. The Debian package for 4.9.3 was prepared.
