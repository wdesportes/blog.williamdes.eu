Report for January 2020

Author: William Desportes
Published: January 1, 2020 12:00 and updated: November 10, 2026 12:00 · 15 min read

Here is my phpMyAdmin report for January 2020.

In January 2020 I fixed a lot of bugs on the main repository, started several Debian packaging efforts and fixed old links on the website. I also opened a pull-request to get phpMyAdmin into the docker library's official images, and one on the Laravel framework so that a command that is not confirmed returns exit code 1.

First week (1)

I merged a set of bug fixes on the main repository: an uncaught TypeError in the setup, the tab focus using the refresh button, the tooltip z-index, the warning popup not disappearing and the double icon on the enum editor. I also fixed a SQL injection in the user exists request. And I started the Debian packaging of mariadb-mysql-kbs with the 1.2.8 import.

Second week (2)

I fixed quite a bunch of issues on the main repository: in the Designer the page names now have to be unique, a view named 'views' no longer gets an expand button, and relating a view to a table no longer throws a PHP error. I fixed 2FA being disabled, and 500 errors on the privileges page and on the table overview pagination. I also added unit tests for the cookie decryption and fixed the CI after sql-parser 4.5.0. On the Debian side I uploaded phpmyadmin 4.9.4 with the CVE-2020-5504 fix and sql-parser 4.5.0.

Third week (3)

I merged more fixes on the main repository: the Relation view, the enum fields being reset when editing, the missing table borders on the original theme, and SET AUTOCOMMIT=0 removed from the export. I added the ONLINE transaction support (ALGORITHM=INPLACE, LOCK=NONE) for indexes and replaced facebook/webdriver by php-webdriver/webdriver. I also started the Debian packaging of twig-i18n-extension. On the docker repository I replaced the maintainer, because Michal Čihař resigned from phpMyAdmin, and fixed the Maintainers format of the stackbrew library script.

Fourth week (4)

More bug fixing on the main repository: integer validations on the search page (with support for unsigned integers), the PROCESSLIST content, the font sizing and the database names starting with "b" being cut off on the user account page. I taught the server-side HTTPS detection about the Forwarded header (RFC 7239). On the website I fixed a lot of old links: https everywhere, debconf13, the awards, the demo links, and I removed the Google+ link. And I uploaded mariadb-mysql-kbs 1.2.9 to Debian, with tests that no longer need Internet access.
