Report for February 2020

Author: William Desportes
Published: February 1, 2020 12:00 and updated: November 10, 2026 12:00 · 14 min read

Here is my phpMyAdmin report for February 2020.

In February 2020 I fixed bugs on the main repository, spent a lot of time making the test suite pass on Windows and did several Debian uploads.

First week (6)

I fixed a set of PHP notices and TypeErrors on the main repository, about the missing global lang, the missing PHP extensions and the Relation view of a view, and I improved some documentation URLs. On sql-parser I merged two contributions: replacing sscanf by native PHP functions because it can be disabled for security reasons, and stopping to instantiate an object to check its class name. On other repositories I added a .gitattributes file to laravel-translatable and fixed a typo in validate-json-action.

Second week (7)

A lot of the week went into the Windows test suite: CRLF issues, locale and some TypeErrors. I merged several fixes (sorting tables by size or by rows, "insert as new row" and the "Show Query" button) and upgraded php-webdriver to 1.8 for the W3C capabilities. On sql-parser I fixed a lexer conflict when */* was in a query and removed the deprecated TravisCI config. And I uploaded tcpdf 6.3.4 to Debian.

And I uploaded twig-i18n-extension 2.0.0 and tcpdf 6.3.5 to Debian.
