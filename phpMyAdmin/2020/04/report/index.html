Report for April 2020

Author: William Desportes
Published: April 1, 2020 12:00 and updated: November 10, 2026 12:00 · 11 min read

Here is my phpMyAdmin report for April 2020.

In April 2020 I fixed bugs, upgraded the vendored JavaScript libraries and added Psalm to the project. I also sent pull-requests upstream, to be able to sync the jQuery plugins from npm, and a few to angular/universal and nlp.js.

First week (14)

I did some documentation improvements and removed the last references to the removed mcrypt extension. I also fixed the TypeError on htmlspecialchars, allowed NULL as a default bit value and added proper CSS classes to HTML elements.

Second week (15)

I upgraded most of the vendored JavaScript libraries (jquery, codemirror, popper.js, zxcvbn, js-cookie, jquery-validation, tracekit) and improved the sync script. I removed sami/sami from the dev-dependencies. On sql-parser I merged a fix so that EXISTS is also parsed as a function. To be able to sync the jQuery plugins from npm I sent pull-requests to cowboy/jquery-hashchange, code-lts/jquery-uitablefilter, code-lts/jquery-fullscreen-plugin and dfilatov/jquery-plugins.
