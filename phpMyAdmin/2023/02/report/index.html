Report for February 2023

Author: William Desportes
Published: February 1, 2023 12:00 and updated: November 10, 2026 12:00 · 6 min read

Here is my phpMyAdmin report for February 2023.

In February 2023 my focus was bug fixing on phpmyadmin and sql-parser, and the Debian package of 5.2.1.

First week (5)

I merged #420 on sql-parser, a new unit test and a fix for ALTER EVENT RENAME TO using an expression. On the Debian package of phpmyadmin I installed the ChangeLog using dh_installchangelogs.

  • e1b21e1e87 - Update .out data

  • 8e48df31bf - Merge #420 - Provide new unit test + fix with ALTER EVENT RENAME TO using expression
  • 59b1088719 - Install ChangeLog using dh_installchangelogs

Second week (6)

I merged #17923 to allow opening the copy and edit row actions in a new tab (#17766), and #17851 to re-build the query count management (#17028 and #17683). On the website I officially declared support for PHP 8.1 and 8.2 on the 5.2 and 5.3 series, and on the Debian side I sent 4:5.2.1+dfsg-1 to unstable.
