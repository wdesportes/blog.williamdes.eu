Here is my phpMyAdmin report for July 2023.

In July 2023 I fixed a good batch of issues on phpmyadmin, and worked on the docker image and docker-library/official-images.

First week (27)

I merged #418 on docker to improve the fix made in #417, and updated phpmyadmin to the latest upstream changes in docker-library/official-images.

  • 30db079919 - Merge #418 - improve the fix made in #417

I implemented the Permissions-Policy security header (#17009) and merged #18379 to fix the double tap to edit on mobile (#14411). I also fixed the hex representation of integers (#18325) and stopped reloading the navigation tree when nothing changed (#17443).
